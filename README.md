# Volasense
Volasense is a cryptocurrency risk monitoring and forecasting system that uses Natural Language Processing (NLP) to analyze social media sentiment and GARCH computational modeling to predict market volatility. The system converts crypto-related posts into a Fear & Greed Index, then uses these sentiment scores to forecast risk levels and visualize potential market instability.

install: pip install streamlit pandas numpy plotly requests vaderSentiment arch yfinance
Run streamlit run main.py
